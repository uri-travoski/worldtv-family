# WorldTV family copies (private)

Set-up-for-you copies of [WorldTV](https://github.com/uri-travoski/iptv-player) for family members.
Each one is the normal release APK plus `assets/preset.json` (playlist, PIN, TV layout, channel check),
re-signed with the same key, so normal WorldTV updates install over it and keep the setup.

**Keep this repository private:** the APKs contain playlist logins. Download them from Releases.

| Copy | Release |
|---|---|
| dvd | Latest: https://github.com/uri-travoski/worldtv-family/releases/latest/download/WorldTV-RTU-dvd.apk (sign in to GitHub first) |
